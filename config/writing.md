# Writing rules for phase 2 drafts

Example preferences for the made-up candidate.

- Plain, direct prose. Concrete specifics over adjectives. One page.
- Make the argument for fit ("this role needs X; here is where I did X"), not a recital of the CV.
- Name a real gap honestly in one sentence.
- Never claim experience the candidate does not have.
- Output PDF named `[Full name] Cover Letter [Company]`.
